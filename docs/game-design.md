# 浮岛小家（暂名）— 游戏设计文档 v0.1
2026-11-04 ｜ 平台 iOS（SwiftUI + SceneKit）｜ 一次性买断，无广告、无体力、无抽卡
依据：docs/player-research.md

## 1. 定位
一座漂浮在粉金色天空里的小岛：小屋、菜园、樱花树、花丛、带木栈道的池塘、从岛边落下的瀑布、一只猫。
玩家按自己的节奏种植、装修、扩岛。**白天是主视觉**：明亮、暖、高饱和、粉彩天空——一眼吸睛、治愈。

## 2. 核心循环
1. **种**：菜园/花圃播种 → 实时（可选加速）生长 → 收获作物与花。下雨自动浇水。
2. **换**：作物/花换取“岛币”，在确定性商店（每季固定目录 + 制作配方）解锁家具，不靠运气。
3. **装**：装修模式里摆放、旋转、组合；装饰提升“温馨度”，吸引小动物来访。
4. **扩**：温馨度/委托进度解锁扩岛（新浮块用桥相连，买到的地必须全部可用）。
5. **轻目标**：季节小委托（“春天在池边放 3 盏灯笼”）、家具/作物/访客**图鉴**、拍照模式。没有失败、没有每日打卡惩罚。

## 3. 装修系统（调研要点落地）
| 规则 | 设计 |
|---|---|
| 吸附 | 默认**半格吸附**（0.5 格）；一键切**自由模式**（不吸附，可 45°/自由旋转） |
| 旋转 | 半格模式 45° 步进；自由模式支持双指旋转任意角度 |
| 表面槽位 | 小物件（灯笼、花盆、杯子）可放在桌面/柜台/架子上；地毯可压在家具下 |
| 居中 | 物件以中心点吸附，1 格椅可对齐 2 格桌中线；墙挂件支持居中吸附 |
| 光标装修 | 俯视光标 + 拖拽，**全量目录**直接取用，无背包上限、无需跑仓库；按类别/颜色/风格筛选 |
| 灯光 | **所有灯具真实发光**（点光源 + 自发光 + 泛光），随昼夜/天气自动亮起 |
| 活的院子 | 装饰吸引访客：鸟屋→小鸟、水碗→猫、蜂箱→蜜蜂、花丛→蝴蝶；家具可坐（猫/角色会坐长椅） |
| 成套 + 改色 | 每个系列保证核心件齐全；提供调色板 |
| 撤销 | 每步可撤销；无数量上限、无等待 |
| 解锁 | 全部确定性：商店目录 + 制作配方 + 委托奖励 |

## 4. MVP 范围（首个可上架版本）
- 1 座初始岛 + 2 次扩岛；昼夜 + 晴/多云/雨（含雷）+ 4 季皮肤
- 作物 6 种、花 6 种；家具约 60 件（3 个系列 + 灯具 10 件）；访客 4 种
- 装修模式（上表全部规则）、拍照模式（隐藏 UI、时间天气切换、保存相册）
- 季节委托 12 个、图鉴；iCloud KVS 存档；中/英
- 一次性买断（或免费试玩初始岛 + 一次性解锁完整版，二选一待定）

## 5. 美术与渲染管线
- **3D → 像素**：SceneKit 渲染到低分辨率离屏目标（像素分辨率可调，短边 270–1080，默认 540），最近邻放大；UI 用原生分辨率保持清晰。
- 后处理（SCNTechnique + Metal）：深度边缘检测 **1px 深色描边**；暖色小范围泛光。后续加法线边缘、色阶量化/调色板映射。
- 正交等距相机（约 45° 偏航、30° 俯角），可旋转/缩放；硬阴影。
- 动态：树冠摇摆（geometry shader modifier）、烟囱炊烟、水面波光、瀑布流动、夜晚萤火虫、雨 + 闪电。
- 调色：白天粉蓝天 + 奶油粉地平线；黄昏粉金；夜晚是“蓝紫色的温柔夜”，不压暗。
- **模型来源**：优先免费 CC0（Quaternius、Kenney），在 CREDITS.md 登记；Meshy AI（密钥在 ~/.secrets/meshy_api_key）只用于缺口的标志性物件（小屋、猫），节省额度。统一导出低面数、扁平色，像素化后风格一致。
